# Prediction Checker

Public site of Prediction Checker, the international sister of [@voorspellingchk](https://x.com/voorspellingchk): predictions by well-known people and institutions, and whether they came true.

- `index.html` – the site (static, no server needed)
- `data.json` – all predictions and checks
- `tools/apply_updates.py` – merges changed and deleted predictions into `data.json`

Spotted a prediction? Send a tip via the button on the site.
